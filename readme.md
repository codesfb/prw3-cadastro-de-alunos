# 📝 Cadastro de Alunos

Um sistema de console simples para gerenciar o cadastro de alunos, desenvolvido em Java. O projeto utiliza JPA/Hibernate para persistência de dados em um banco de dados H2.

## ✨ Funcionalidades

- **Cadastrar Alunos:** Adicione novos alunos ao sistema.
- **Listar Alunos:** Veja a lista completa de alunos cadastrados, com suas notas, média e situação (Aprovado, Recuperação ou Reprovado).
- **Buscar Aluno:** Procure por um aluno específico pelo nome.
- **Alterar Dados:** Modifique as informações de um aluno existente.
- **Excluir Aluno:** Remova um aluno do sistema.

## 🛠️ Tecnologias Utilizadas

- **Java 21:** A linguagem de programação principal.
- **Maven:** Para gerenciamento de dependências.
- **JPA (Jakarta Persistence API):** Para o mapeamento objeto-relacional.
- **Hibernate:** A implementação do JPA.
- **H2 Database:** Um banco de dados em memória para armazenamento dos dados.
